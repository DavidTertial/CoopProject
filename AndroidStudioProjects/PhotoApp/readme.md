# Photo Gallery App 📸

An Android application built with **Kotlin** that displays photos and videos from a user’s device in a clean, responsive grid layout. The app allows users to preview media and share selected files through other applications.

---

## 📌 Description

The Photo Gallery App provides a simple and efficient way to browse media stored on an Android device. It reads photos and videos from device storage, presents them in a grid-based UI, and supports media preview and sharing functionality.

This project focuses on Android fundamentals such as media access, UI composition, and inter-app communication.

---

## ✨ Features

- Display photos and videos from device storage
- Grid-based media layout
- Image and video preview
- Share media via other apps (e.g., messaging or social apps)
- Smooth navigation between screens
- Modern Android UI design

---

## 🛠️ Tech Stack

- **Language:** Kotlin  
- **Framework:** Android SDK  
- **UI:** Jetpack Compose / XML (depending on implementation)  
- **Tools:** Android Studio  
- **APIs:** Android MediaStore, Intent system

## ▶️ How to Run

### Requirements
- Android Studio
- Android device or emulator (Android 8.0+ recommended)

### Steps
1. Open the project in **Android Studio**
2. Sync Gradle dependencies
3. Connect an Android device or start an emulator
4. Click **Run**
